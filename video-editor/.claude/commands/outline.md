Follow PLAYBOOK.md stage 3 using `projects/$1/brief.md` (needs `## Packaging` and `## Promise`; if they're missing, run /package first).

1. **Hook script** (aim for ≤30 seconds spoken, in the creator's own plain voice, no hype words), answering in order:
   - Promise: confirm they got what they clicked for, ideally in the first sentence.
   - Proof: why listen? Show it, don't claim it (the result on screen, failures survived, hours spent).
   - Plan: the steps the video will cover.
   - Persona: who this is for (one line, only if the package could attract the wrong viewer).
2. **Acceptance criteria**: decompose the title: "what must be true by the end for this title to be honest?" Then break each answer down until each item is a concrete, filmable or showable thing. Number them.
3. The numbered criteria **are the outline**. Order them so real value arrives as early as possible.
4. Add a "beat the expectation" item: one thing that delivers more than the package promised.
5. Write `## Hook` and `## Acceptance criteria` into brief.md. Keep other sections.
