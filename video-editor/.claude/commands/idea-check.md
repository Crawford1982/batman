Follow PLAYBOOK.md stage 1 for this idea: $ARGUMENTS
Project folder: `projects/$1/` (create it if missing).

1. Turn the idea into 3–5 search phrases a viewer would actually type.
2. Research YouTube demand with web search (and any vidIQ/Studio numbers the user pastes). For each phrase, list the top ~5 relevant videos: title, channel size, views, age.
   - **Floor** = typical views of a decent video on it; **ceiling** = the best performers. Flag outliers that are huge relative to their channel's size (strong demand signal) and ones that look botted.
   - **Currency**: are videos from the last 6–12 months still pulling views?
3. Suggest 2–3 ways to **stack demand** to raise the ceiling (attach to a bigger character, film, creator or event the same audience already chooses), and say why each fits *this* audience.
4. Verdict: GO / RESHAPE / DROP, with one-line reasoning. If you couldn't find real numbers, say so; don't invent view counts.
5. Write or update `projects/$1/brief.md` with sections `## Idea`, `## Demand (floor/ceiling + sources)`, `## Verdict`. Keep any existing sections.
